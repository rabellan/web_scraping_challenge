# Mission To Mars Web Scraping Challenge
## Requirements
1. Scrape titles and preview text from Mars News
    1. Automate browsing (with Splinter) to visit the Mars news site, and extract the HTML code (with Beautiful Soup).
    2. Scraped and extract the titles and preview text of the news articles.
    3. Scrape the information stored in the specified Python data structure—specifically, a list of dictionaries.
2. Scrape and Analyze Mars Weather Data
    1. Extract table, put it in a Pandas DataFrame, and analyze data to answer the following questions?
        1. How many months exist on Mars?
        2. How many Martian days' worth of data are there?
    2. Analyze the data to answer the following questions:
        1. Which month, on average, has the lowest temperature? The highest?
        2. Which month, on average, has the lowest atmospheric pressure? The highest? 
        3. How many terrestrial days exist in a Martian year? A visual estimate within 25% was made.
    3. Export the dataframe into a CSV file
